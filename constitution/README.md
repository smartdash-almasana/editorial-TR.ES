# Constitución Editorial

En este directorio residen los principios editoriales universales y reglas normativas supremas que **ningún plugin, prompt ni modelo de IA podrá vulnerar**.

## Principios
- **Supremacía constitucional:** Las reglas definidas en este directorio prevalecen sobre cualquier instrucción de prompt o plugin.
- **Protección de la calidad:** Garantía de coherencia, ética y rigor editorial.
- **Aprobación humana obligatoria:** Toda modificación sobre el manuscrito debe ser aprobada explícitamente por un editor humano.
