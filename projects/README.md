# Proyectos Editoriales (Projects / Inkwell)

En este directorio residirán las obras editoriales individuales en formato Markdown legible por humanos (*Inkwell*), acompañadas de sus archivos de configuración y manifiesto de composición de plugins.

## Responsabilidades
- Mantener la estructura de archivos fuente, notas de investigación y activos gráficos de cada obra.
- Declarar la combinación específica de plugins (género, voz, estilo, workflow, outputs) mediante un manifiesto de proyecto.

## Limites
No ejecuta la plataforma; sirve como almacenamiento del código fuente y artefactos del proyecto.
