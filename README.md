# Editorial Factory

Plataforma modular para constituir, producir, revisar, ilustrar y preparar obras literarias para su publicación.

## Propósito

Editorial Factory será una fábrica editorial extensible, preparada para trabajar con distintos:

- géneros literarios;
- voces autorales;
- voces narrativas;
- estilos;
- métodos de revisión;
- formatos visuales;
- salidas de publicación.

La plataforma deberá permitir producir:

- manuscritos;
- libros ilustrados;
- infografías;
- láminas;
- ilustraciones;
- paquetes app-book;
- PDF;
- otros artefactos editoriales.

## Separación respecto de TRES

Editorial Factory produce y aprueba obras.

TRES publica, distribuye y permite leer las obras aprobadas.

Ambos sistemas se mantienen en repositorios independientes.
