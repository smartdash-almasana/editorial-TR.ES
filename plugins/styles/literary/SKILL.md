# Style Plugin — Literary

Este plugin modula la expresión formal de una obra sin reemplazar la voz autoral.

## Propósito

- sostener precisión y fuerza expresiva;
- modular ritmo y cadencia;
- mejorar selección léxica;
- evitar prosa formularia o genérica;
- preservar variación, ambigüedad y desviaciones deliberadas cuando cumplen una función literaria.

## Límite

El estilo no define la identidad permanente del autor, no decide el narrador y no puede aplicar cambios por fuera del flujo `ReviewFinding → decisión → EditorialPass → Patch → ApprovalGate`.
