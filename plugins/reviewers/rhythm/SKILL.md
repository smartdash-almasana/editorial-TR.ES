# Reviewer de ritmo

Detecta señales rítmicas reproducibles en bloques de expresión: secuencias de oraciones muy cortas o muy largas, uniformidad extrema de longitud y aperturas repetidas.

No decide si el ritmo es bueno o malo. Cada hallazgo solicita revisión humana para determinar si el patrón es deliberado. No modifica `Work`, no crea `Patch` y no aplica transformaciones.
