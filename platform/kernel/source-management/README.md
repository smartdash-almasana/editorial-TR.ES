# Source Management (STORM)

Gestión de fuentes de investigación, referencias y notas de contexto.

## Responsabilidades
- Mantener la separación entre la etapa de investigación (fuentes, esquemas, referencias) y la etapa de redacción del manuscrito.
- Organizar el material de consulta disponible para el proyecto sin contaminar el texto principal.
- Facilitar trazabilidad de citas y respaldo documental de las afirmaciones del texto.

## Limites
No redacta capítulos finales; almacena y estructura conocimiento previo o auxiliar.
