# Factoría Literaria

Subsistema responsable de guiar la producción de manuscritos y texto literario.

## Responsabilidades
- Generar y refinar bloques de texto alineados con las directivas del género, voz y narrador activos.
- Coordinar la interacción con el kernel para la actualización incremental del manuscrito.

## Limites
No toma decisiones de diseño gráfico ni gestiona empaquetados finales; se enfoca exclusivamente en la palabra escrita y su estructura.
