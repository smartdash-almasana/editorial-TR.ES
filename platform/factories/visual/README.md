# Factoría Visual

La factoría visual es una unidad de producción central (no accesoria) dentro de Editorial TR.ES.

## Productos Visuales

Esta factoría producirá:

- infografías;
- láminas;
- ilustraciones;
- diagramas;
- portadas;
- recursos pedagógicos;
- piezas para PDF;
- piezas para app-book.

## Ciclo de Vida de Producción Visual

El flujo de trabajo visual sigue estrictamente las siguientes etapas:

1. **Análisis conceptual**: Extracción de requerimientos clave del texto o capítulo.
2. **Brief visual**: Especificación formal de estilo, paleta, composición, sujeto y datos.
3. **Generación de imagen**: Producción de arte base mediante modelos de generación visual.
4. **Composición tipográfica**: Superposición y diagramación de texto, etiquetas y vectores sobre el arte base.
5. **Validación**: Verificación de reglas editoriales, coherencia visual y legibilidad.
6. **Aprobación**: Visto bueno del editor humano sobre el artefacto compuesto.
7. **Exportación**: Generación de activos finales en formatos vectoriales/rasterizados para sus destinos.

## Regla de Independencia Tipográfica

El texto final de las infografías y láminas **no debe depender exclusivamente del modelo generador de imágenes**. Toda la tipografía, etiquetas informativas y elementos de lectura crítica se componen y renderizan en una capa independiente (vectorial/layout), garantizando nitidez, traducibilidad, corrección tipográfica y control editorial exacto.
